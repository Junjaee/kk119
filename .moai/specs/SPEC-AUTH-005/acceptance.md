# SPEC-AUTH-005: Remember Me 기능 - 인수 기준

## 핵심 기능 인수 기준

### AC-001: Remember Me 로그인

**Given** (전제 조건):
- 사용자가 로그인 페이지에 접속했다

**When** (실행):
- 사용자가 "로그인 상태 유지" 체크박스를 선택한다
- 올바른 아이디/비밀번호로 로그인한다

**Then** (결과):
- 30일 유효한 장기 토큰이 쿠키에 저장된다
- 브라우저를 닫았다가 다시 열어도 로그인 상태가 유지된다

---

### AC-002: 신뢰 디바이스 해제

**Given** (전제 조건):
- 사용자가 3개의 디바이스를 신뢰 목록에 추가했다

**When** (실행):
- 사용자가 설정 페이지에서 디바이스 하나를 해제한다

**Then** (결과):
- 해당 디바이스의 장기 토큰이 무효화된다
- 해당 디바이스에서 다음 접속 시 재로그인이 필요하다
