# SPEC-AUTH-006: 동시 세션 제한 및 관리 - 인수 기준

## 핵심 기능 인수 기준

### AC-001: 최대 3개 세션 제한

**Given** (전제 조건):
- 사용자가 이미 3개의 디바이스에서 로그인되어 있다

**When** (실행):
- 사용자가 4번째 디바이스에서 로그인한다

**Then** (결과):
- 가장 오래된 세션이 자동으로 종료된다
- 해당 디바이스에서 API 요청 시 401 Unauthorized 응답을 받는다
- 새 디바이스는 정상적으로 로그인된다

---

### AC-002: 원격 로그아웃

**Given** (전제 조건):
- 사용자가 3개의 디바이스에서 로그인되어 있다
- 사용자가 설정 페이지 `/settings/sessions`에 접속했다

**When** (실행):
- 사용자가 특정 세션의 "로그아웃" 버튼을 클릭한다

**Then** (결과):
- 해당 세션이 무효화된다
- 해당 디바이스에서 다음 API 요청 시 401 응답
- 다른 세션은 영향받지 않는다
