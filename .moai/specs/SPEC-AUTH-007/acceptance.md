# SPEC-AUTH-007: 로그인 시도 알림 시스템 - 인수 기준

## 핵심 기능 인수 기준

### AC-001: 실패 시도 알림

**Given** (전제 조건):
- 사용자가 알림 설정을 활성화했다
- 사용자가 2회 로그인 실패 기록이 있다

**When** (실행):
- 사용자가 3번째 로그인 실패를 한다

**Then** (결과):
- 실패 시도 알림 이메일이 발송된다
- 이메일에는 실패 시도 횟수, IP 주소, 시간이 포함된다
- "비밀번호 재설정" 링크가 포함된다

---

### AC-002: 새 디바이스 알림

**Given** (전제 조건):
- 사용자가 이전에 Windows PC에서만 로그인했다
- 알림 설정이 활성화되어 있다

**When** (실행):
- 사용자가 새로운 디바이스(Android)에서 로그인한다

**Then** (결과):
- 새 디바이스 알림 이메일이 발송된다
- 이메일에는 디바이스 정보, IP 주소, 로그인 시간이 포함된다
- "본인이 아니라면 비밀번호를 변경하세요" 안내 포함

---

### AC-003: 이상 IP 탐지

**Given** (전제 조건):
- 사용자가 한국에서만 로그인했다 (IP 기록)
- 알림 설정이 활성화되어 있다

**When** (실행):
- 사용자가 미국 IP 주소에서 로그인한다

**Then** (결과):
- 이상 IP 탐지 알림 이메일이 발송된다
- 이메일에는 새로운 국가/지역 정보가 포함된다
- 로그인이 허용되지만 보안 경고가 기록된다
